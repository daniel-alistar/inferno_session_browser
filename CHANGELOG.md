# Changelog

## 0.1.0

- Require-only activation of a read-only session dashboard.
- Server-side pagination, suite/option/date/state/URL filters, and current test-result summaries.
- Expandable, paginated run history and links to existing Inferno session pages.
- Packaged frontend assets, configurable mount/input names, and base-path support.
- SQLite and PostgreSQL coverage with Inferno Core 1.4.0 and 1.4.4.
